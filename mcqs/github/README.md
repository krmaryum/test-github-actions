## Recommended Workflow

```bash
git status
git add .
git commit -m "Add my Day 04 assignment"
git pull --rebase origin main
git push origin main
```

Before running the local pull command, sync your fork on GitHub when the original repository contains new changes:

```text
Sync fork → Update branch
```

## Learning Objective

After completing this quiz, learners should be able to follow this workflow confidently:

```text
Fork the original repository
        ↓
Clone your fork
        ↓
Work in your local repository
        ↓
Create or modify files
        ↓
Commit your local work
        ↓
Sync your GitHub fork
        ↓
Pull remote changes with rebase
        ↓
Push your commits to your fork
```
